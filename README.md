# Sales Analysis Dashboard

## Project Overview

This project is an Excel-based Sales Analysis Dashboard designed to analyze sales performance and provide clear, interactive insights from sales data.

The project includes data cleaning, transformation, analysis, and visualization using Microsoft Excel features such as PivotTables, PivotCharts, slicers, and calculated fields.

## Objectives

* Analyze overall sales performance.
* Track sales trends across different months.
* Compare sales between different regions.
* Analyze product and category performance.
* Create an interactive dashboard for easier decision-making.
* Transform raw sales data into meaningful business insights.

## Dataset

The dataset contains sales transactions with the following fields:

| Column          | Description                         |
| --------------- | ----------------------------------- |
| `Order_ID`      | Unique order identifier             |
| `Customer_Name` | Customer name                       |
| `Product_Item`  | Product purchased                   |
| `Category_Type` | Product category                    |
| `Order Date`    | Date of the order                   |
| `Sales_Region`  | Region where the sale occurred      |
| `Qty`           | Quantity sold                       |
| `Unit_Price`    | Price per unit                      |
| `Total_Sales`   | Total value of the sale             |
| `Month_name`    | Month extracted from the order date |

## Workbook Structure

### Raw_Sales_Data

Contains the original sales transaction data used for the analysis.

### mon

Contains monthly sales analysis and summarizes total sales by month.

### regoin

Contains regional sales information and analysis.

### Dashboard

Contains the final interactive sales dashboard with charts and visualizations.
